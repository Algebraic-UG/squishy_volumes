# Installation

The first step is to install Blender and the Squishy Volumes extension.

## Blender

The Squishy Volumes Extension runs within Blender, so <a href="https://www.blender.org/download/">download Blender</a> if you haven't already. This <a href="https://www.youtube.com/watch?v=-tbSCMbJA6o&t=50s">section</a> of Blender Guru's beginner video got you covered if you've never done this.

> [!IMPORTANT]
> The Squishy Volumes extension currently requires Blender 5.0, 5.1, or 5.2.

Unpack or install and start Blender.
