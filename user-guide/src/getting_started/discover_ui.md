# Discover UI

With everything installed, we have to find the UI.

## Sidebar

The most important Squishy Volumes UI is in the sidebar, which is hidden by default.
You can open the sidebar either by pressing the hotkey 'n' or by clicking on that tiny arrow:

<img src="where_is_the_sidebar.svg" alt="Where is the sidebar?">

## Squishy Volumes Tab

Within the sidebar, most likely at the very bottom, there is the Squishy Volumes tab!
Click on that.

<img src="where_is_squishy_volumes.svg" alt="Where is Squishy Volumes?">

We have discovered the Squishy Volumes UI!

Now there is only this one panel 'Overview' with two buttons to start with, but this space will soon be populated with all the knobs and buttons that are relevant to Squishy Volumes.

<img src="discovered_ui.svg" alt="Discovered UI">

Kick in the next gear, we're about to simulate an [example setup](example_setup.md).
