# [0.3.3] - 2026-08-05

The most prominent update is the new logo and user guide!
This is accompanied by a bunch of bug fixes that were relatively simple to implement but make a big difference in user experience.

## Features
- New logo!
- [User Guide](https://squishy-volumes-docs.algebraic.games/) is started ([issue](https://github.com/Algebraic-UG/squishy_volumes/issues/26))
- Modifier's socket drivers can be (re)added with new operator ([pr](https://github.com/Algebraic-UG/squishy_volumes/pull/295))

## Changed
- The default for the 'Confirm Override' preference is now `False` ([pr](https://github.com/Algebraic-UG/squishy_volumes/pull/294))
- All menu operators are now called 'Squishy Volumes <..>' ([pr](https://github.com/Algebraic-UG/squishy_volumes/pull/296))

## Fixed
- Multiple example setups ([issue](https://github.com/Algebraic-UG/squishy_volumes/issues/261))
- Duplicate info in error messages ([issue](https://github.com/Algebraic-UG/squishy_volumes/issues/239))
- GPU now also checks for (nearly) inverted particles ([issue](https://github.com/Algebraic-UG/squishy_volumes/issues/289))
- Reloading same file ([issue](https://github.com/Algebraic-UG/squishy_volumes/issues/287))
- Example setup dialog window size ([issue](https://github.com/Algebraic-UG/squishy_volumes/issues/279))
- Output objects in edit mode are no longer 'desynced' ([issue](https://github.com/Algebraic-UG/squishy_volumes/issues/279))
